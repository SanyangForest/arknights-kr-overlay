# 명일방주(중섭) 화면 지도

오버레이가 화면마다 자주 틀리는 부분을 바로잡도록 만든 기록이다. 2026-10-27 게임을 직접 돌아다니며 만들었다
(기록: `captures/session6`, 화면별 점검: `captures/session6_screens.md`).

- `screens.json`: 화면 목록. 화면마다 **고정 문구**(그 화면에만 나오는 글자), 들어가는 경로, 이어지는 화면, 주로 쓰는 데이터 표.
  오버레이는 OCR 결과로 지금 화면을 판정한다(`screens.py`).
- `ocr_aliases.tsv`: 화면별로 OCR이 늘 같은 식으로 틀리는 문구 → 원래 문구.
- `../extra/claude_screen03.tsv`: 데이터에 없는 화면 글자(배너 그림 글자, 도움말 등)의 번역.

## 이동 구조

```
타이틀 ─START→ 홈
홈 ─┬ 단말기(终端) ─ 아래 탭: 단말기 / 사이드 스토리(曲谱 → 乐章收录) / 자원 수집 / 상시 업무 / 장기 탐색 / 시즌 챌린지
    ├ 편성(编队)
    ├ 오퍼레이터(干员) ─ 카드 → 상세 (좌우로 밀면 다른 오퍼레이터, (i)는 도움말)
    ├ 구매센터(采购中心)   ├ 공개모집(公开招募)   ├ 헤드헌팅(干员寻访)
    ├ 임무(任务)   ├ 기반시설(基建, 나갈 때 확인 창)   ├ 창고(仓库)
    ├ 친구(好友)
    └ 파일(档案) ─ 정보 처리실 ─ 특별행동기술(이벤트 스토리 다시보기, 가로로 넘김)
어디서나 왼쪽 위 집 버튼 → 빠른 이동 메뉴 (홈·편성·오퍼레이터·파일·단말기·기반시설·공개모집·헤드헌팅·구매센터·임무·친구)
```

콜라보 스토리(페르소나 '물 위를 걷는 달' 등)는 기간이 끝나면 다시보기 목록에 없다. 사이드 스토리 목록과 특별행동기술 모두 마지막이 '从林症结'.

## 화면별로 찾은 문제와 처리

| 화면 | 문제 | 처리 |
|---|---|---|
| 홈 | 采购中心 글자가 2×2라 '中采' / '心购'로 읽힘 (감사 축제 홈 테마는 그림 찾기도 안 맞음) | 별칭 '=구매' / '=센터' (session12) |
| 홈 | 이벤트 로고 昨日海를 唯日海·唯仓海로 읽음, 창고를 '包件'으로 읽음 | 별칭 |
| 홈 | 배너 두 줄('寻访现已开放' / '特定干员出率上升')이 하나로 합쳐짐 | 각각 사전에 있는 두 줄은 합치지 않음 |
| 오퍼레이터 상세 | 공격 속도 '慢', 저지 '中等' 등 작은 글자를 OCR이 놓침 | OCR을 1600(원래 크기)으로 |
| 오퍼레이터 상세 | 아이콘+숫자를 '区835', '仓16'으로 읽음 | 잡음으로 보고 번역하지 않음 |
| 오퍼레이터 상세 | 傀儡师를 '愧师', 不羁之力를 '不之力', 모래시계+慢을 '8慢'으로 읽음 | 별칭 |
| 단말기·자원 수집 | 가로 목록 끝에서 잘린 카드 글자('不可进', '固若金') | 화면 끝에 닿은 글자는 잘린 앞/뒤를 사전에서 찾음 (숫자가 다르면 안 씀) |
| 단말기·자원 수집 | 요일 조합(周一二五六开放)이 사전에 없고, 비슷한 문장으로 다른 요일이 걸림 | 요일 규칙으로 직접 번역, 한자 숫자가 다르면 비슷한 문장 안 씀 |
| 사이드 스토리·다시보기 | 로고 제목 한 글자 오독 (从林症结, 现岛风云, 怒潮漂冬, 弓星棘刺…) | 한 글자 틀린 고유명사 교정 + 헷갈리는 글자(丛从, 凛漂, 引弓, 烬炽…) |
| 구매센터 | 'VI'를 'MI'로 읽고 비슷한 문장으로 '/I'를 붙임 | 로마 숫자가 다르면 비슷한 문장 안 씀 |
| 헤드헌팅·구매센터 | 배너 그림 글자(以上干员获得概率提升！, 限时联动时装…)가 데이터에 없음 | 직접 번역 추가 |
| 도움말 창 | 도움말 글이 데이터(엑셀)에 없음 | 직접 번역 추가 |
| 공개모집 | '开始招募干员'이 조각 번역으로 '시작 오퍼레이터 모집' | 직접 번역 추가 |
| 공지 창 | 웹 공지라 데이터에 없음 (이벤트 안내 문장) | 제목 몇 개만 추가. 본문은 아직 안 됨 |
| 홈 | 세로 메뉴 글자(干/员, 任/务, 基/建)를 OCR이 세로로 긴 상자 하나로 읽어, 상자 높이를 글자 크기로 잡아 한글이 아주 크게 세로로 쌓임 | 세로 글자는 한 글자 높이로 재고 가로 한 줄로, 좁으면 한 글자씩 세로로 |
| 홈 | 오퍼레이터 말풍선: 기울어 잡힌 OCR 상자 때문에 글자 높이를 2배로 잡음 | 글자 높이는 OCR 사각형의 변 길이로 잼 |
| 홈 | 终端 로고, 采购中心(2×2), 好友·档案(작은 세로 글자)는 OCR이 못 읽음 | screens.json의 labels: 홈일 때 정해진 자리에 그림 |
| 홈 | 알림 개수 '39'와 옆의 '5天'이 붙어 '395일' | 숫자만 있는 조각은 옆 글자와 잇지 않음 |
| 여러 곳 | 한섭 틀 '{0} 후 개방'에 숫자만 넣어 '1 후 개방' (한섭은 {0}에 '1일'을 넣음) | 원문 변수 뒤 단위가 번역 틀에 없으면 한국어 단위를 붙임 |
| 훈장(光荣之路) | 획득 방법 끝의 진행도 '(0/1)' 때문에 사전 문장과 안 맞음 | 진행도를 떼고 찾은 뒤 다시 붙임 |
| 훈장(光荣之路) | '获得方式' 라벨과 문장이 한 줄로 읽힘, 줄바꿈된 꼬리('名人堂珐琅（1/8）')가 남음 | 라벨+문장 나눠 번역, 윗줄에서 통째로 번역된 문장의 꼬리 줄은 원문만 가림 |
| 훈장(光荣之路) | 훈장 설명의 이벤트 이름 때문에 이벤트 화면으로 판정됨 | 훈장 화면(medals)을 먼저 판정 |
| 홈 | Live2D 배경 캐릭터가 화면의 약 45%를 계속 바꿔, '화면 전환'으로 보고 번역을 계속 지웠다 그림 | 최근 자주 바뀌는 픽셀을 '움직이는 부분'으로 배워 변화 판단에서 뺌. 그 위의 번역(말풍선)은 OCR이 3초 못 읽을 때만 지움 |
| 홈 | 메뉴판이 마우스를 따라 기울어 고정 글자 위치가 어긋남 | refs 글자로 이동량을 계산하고, 원문 글자 그림(templates/)을 주변에서 찾아 맞춤. 못 찾으면 안 그림 |
| 홈 | 창고 위 '5天'을 '?5天'·'Q5天'·'05天'으로 번갈아 읽어 상자가 계속 바뀜 | 숫자+단위 앞 글자 하나·앞자리 0은 아이콘으로 보고 뗌. 짧은 글자는 같은 번역이면 처음 상자 유지, 다른 번역은 두 번 연속 나와야 바꿈 |
| 홈 | '5天'과 바로 아래 '仓库' 상자가 살짝 겹쳐, 한쪽을 놓치면 다른 쪽이 '교체'로 보고 지움 | 대부분 덮을 때만 교체로 봄 |
| 화면 전환 | 0.5초짜리 전환 효과까지 '움직이는 부분'으로 배워, 옛 화면 번역이 몇 초씩 남아 새 글자와 겹침 (통합 전략 이벤트 → 지도) | 4번 넘게 잇달아 바뀌어야 움직이는 부분. 새 글자가 걸친 옛 상자는 글자 그림이 그대로일 때만 남김. 화면 60% 넘게 바뀌면 전환 |
| 홈 | 오퍼레이터 대사 첫 줄의 '……'를 OCR이 빼먹어('嗯博士是…') 줄 합치기가 사전 문장을 못 찾음 | 앞부분 비교에서 머리의 말줄임표 생략 허용, 瞌/嗑 헷갈림 |
| 홈 | 오른쪽 위 배너 '视相博物馆：演化' 장식 글씨를 매번 다르게 읽음('提想博物境演化', '携想博物增演化') | 로고 규칙: 끝 글자가 맞고 로고 글자 절반 이상이 들어 있으면 같은 로고 |
| 전투 | '새 적' 소개창 설명('喝了点酒的杜林人，初始拥有…')이 excel에 없음 | `levels/enemydata/enemy_database.json` 추가 (한국판에 없는 156개는 공식 용어로 직접 번역) |
| 우편 | 날짜와 남은 날수가 붙어 '2026-10-2626日后过期'로 읽힘 | 규칙: (오늘 + 남은 날수) - 받은 날짜가 흔한 보관 기간(30·90·180일 등)에 가까운 쪽으로 나눔 |
| 구매센터(오리지늄) | 상품 이름(开采一组源石…)·双倍·额外赠送이 서버에서 내려와 데이터에 없음 | 직접 번역 추가 |
| 기반시설 | 마우스 커서가 '进驻信息'의 '息'를 가려 '进驻信必', 발전소 '发电中▸▸▸'를 '发电中心→'로 읽음 | 별칭 |
| 오버레이 시작 | 오버레이 창이 처음 뜰 때 게임의 입력 포커스를 가져감 | 뜬 뒤 원래 앞에 있던 창에 포커스를 돌려줌 |
| 오버레이 실행 중 | 잠금 화면·UAC 확인 창이 뜨면 화면 캡처가 실패해 읽기 스레드가 죽고 번역이 멈춤 | 캡처 실패는 1초 뒤 다시 시도 |
| 홈(감사 축제 테마) | 采购中心 고정 글자와 OCR 조각('中采'/'心购')이 번갈아 그려짐. 메뉴판이 마우스를 따라 80px쯤 움직여 글자 그림 찾기(±50px)를 벗어남 | 찾는 범위 ±90px, 고정 글자 자리의 OCR 조각은 고정 글자로 합침 |
| 기반시설 | 숙소 4개처럼 같은 이름이 여럿일 때 OCR이 하나를 놓치면 '같은 번역이 다른 자리에 나옴'으로 보고 지웠다 다시 그림 | 그 규칙은 긴 글(대사)에만 |
| 우편 | '4/100 未读邮件'의 未를 한 번 더 '天'으로 읽어 '4/100 일' 상자가 '미확인'을 가림 | 우편함에서 '개수/개수+天'은 그리지 않음 |
| 우편 | 웹 이벤트 이름(冻土与火种)이 데이터에 없어 틀에 중국어 그대로 들어감 | 직접 번역 추가 |
| 스토리 대사 기록 | 다른 화자의 대사 두 줄('两点之间，直线最短。' / '没错。')이 하나로 합쳐짐 | 둘 다 사전에 그대로 있는 줄은 이은 문장이 사전 문장의 정확한 앞부분일 때만 합침 |
| 자원 수집 | 양 끝 카드의 잘린 요일('周一四五[', '日六日开放')과 잘린 데다 틀리게 읽은 이름('勿运送' = 货物运送) | 보이는 요일만 '월·목·금…' / '…토·일 개방'. 화면 끝 찾기에서도 헷갈리는 글자를 바꿔 봄 |
| 통합 전략 결과 | 로고(凋零残响, 傀影与猩红孤钻)와 기록 줄('您Dr.…使用…历时…驻足在…') | 별칭·로고 규칙, 기록 줄 규칙 |

## 화면을 더 넣는 방법

1. 오버레이를 `--record captures/sessionN`으로 켜고 새 화면을 돌아다닌다.
2. `python screen_report.py ../out/dict_zh_ko.json captures/sessionN` → `captures/sessionN_screens.md`
   - '알 수 없는 화면'에 모인 장면을 보고 `screens.json`에 화면과 고정 문구를 추가
   - '번역 못 한 문구'가 OCR 오독이면 `ocr_aliases.tsv`, 데이터에 없는 글자면 `extra/claude_screen03.tsv`
   - '오역 의심'은 실제로 맞는지 확인
3. 장면 한 장을 자세히 볼 때: `python probe_frame.py ../out/dict_zh_ko.json captures/sessionN/frame_XXXX.png`
